# @shogun-ai/desktop

The ShogunAI macOS app — the Memory layer (passive capture via the macOS
Accessibility API, local storage) and the Execution layer (agent + MCP tools).

**Status:** scaffold only. No implementation yet.

Suggested stack when we build it: Tauri or a native Swift shell around a shared
core. Shared domain logic will come from `@shogun-ai/shared`.
