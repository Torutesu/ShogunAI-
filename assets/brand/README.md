# Brand assets

Source artwork and dock/marketing variants for SHOGUN. Not bundled into the desktop app at runtime.

## Canonical sources

| File | Role |
|------|------|
| `logo.png` | Master raster (fan mark). Input for `scripts/trace_logo.py` and `scripts/generate_dock_icons.py`. |
| `logo.svg` | Traced vector from `logo.png` (regenerated by `trace_logo.py`). |
| `FINAL_DOCK_LOGO.png` | Canonical dock / app-icon source art (hand-tuned). Prefer this when updating `apps/desktop/src-tauri/icons/`. |
| `logo-dock.png` | Dock variant export (working copy; may match or precede `FINAL_DOCK_LOGO.png`). |

## Generated / variant PNGs

Produced by `scripts/generate_dock_icons.py` (or kept as references):

- `logo-transparent-blue.png`
- `logo-light-bg-blue.png`
- `logo-dark-bg-white.png`
- `logo-white-bg-black.png`

## Design exports

- `Group 3.png` — Figma/export reference (not used by build).

## App bundle icons

Runtime icons live under `apps/desktop/src-tauri/icons/` (including `logo-mark.svg`, tray PNGs). Regenerate from scripts above; do not point the app at this folder directly.

## Legacy

`legacy/assets/logo.svg` is a separate copy for the legacy static site.
