# 実ロゴの出典

Dock に使っている本物のブランドマーク。すべて Wikimedia Commons から取得（自由ライセンス）。
各社の商標であり、製品デモ内で当該アプリを指す目的でのみ使用している。

| ファイル | Commons のファイル名 |
|---|---|
| `slack.svg` | Slack icon 2019.svg |
| `chrome.svg` | Google Chrome icon (February 2022).svg |
| `gemini.svg` | Google Gemini icon 2025.svg |
| `notion.svg` | Notion-logo.svg |
| `line.svg` | LINE logo.svg |
| `figma.svg` | Figma-logo.svg |

Apple 製アプリ（Finder / Safari / Mail / Calendar など）のアイコンは非自由ライセンスのため
Commons に無く、取得できていない。これらは `index.src.html` 内の描画版のままである。
実物にしたい場合は README の「Dock を実物のスクショに差し替える」を使うこと。
