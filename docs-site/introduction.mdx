SHOGUN runs on your Mac and builds a working model of what you do. It reads
your screen through the macOS Accessibility API — text, not screenshots — keeps
that memory local, and gives agents enough context to finish work instead of
describing it.

Two layers, one product:

## What SHOGUN is not

- **Not a recorder.** No screenshots, no screen recordings, no audio files on
  disk. Visual recall is opt-in and stores encrypted frames for a retention
  window you choose.
- **Not a note app.** Memory is a means to execution, not the deliverable.
- **Not cloud-first.** Capture, storage, search and embeddings run on device.
